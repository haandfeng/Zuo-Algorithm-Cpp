# 前缀和 & 差分

> **TL;DR**：前缀和 = "区间求和的 O(1) 利器"；差分 = "区间修改的 O(1) 利器"。两者是**互逆**操作，思路完全对称。

## 一维前缀和

```cpp
vector<int> a(n), pre(n + 1);
for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + a[i];
// pre[i] = a[0] + a[1] + ... + a[i-1]
// 区间 [l, r] 之和 = pre[r + 1] - pre[l]
```

**注意下标偏移**：`pre[i+1]` 对应"前 i+1 个元素之和"。这种偏移让求 `[l, r]` 不需要特判 `l = 0`。

### 应用：和为 K 的子数组（LC 560）

```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> cnt;     // 前缀和 → 出现次数
    cnt[0] = 1;                       // 空前缀
    int sum = 0, ans = 0;
    for (int x : nums) {
        sum += x;
        if (cnt.count(sum - k)) ans += cnt[sum - k];
        cnt[sum]++;
    }
    return ans;
}
```

**核心**：以 j 结尾、和为 k 的子数组数 = `cnt[pre[j+1] - k]`。把"区间和"转成"前缀和差"，再用 hash 计数 → O(N)。

## 一维差分

差分数组 `d[i] = a[i] - a[i-1]`（`d[0] = a[0]`）。

性质：

- **a 的前缀和 = d**
- **d 的前缀和 = a**
- 给 `a[l..r]` 全部加 `v` ⟺ `d[l] += v; d[r+1] -= v`

```cpp
vector<int> d(n + 1, 0);
auto rangeAdd = [&](int l, int r, int v) {
    d[l] += v;
    d[r + 1] -= v;
};

// 多次 rangeAdd 后还原 a：
vector<int> a(n);
a[0] = d[0];
for (int i = 1; i < n; ++i) a[i] = a[i - 1] + d[i];
```

**适用场景**：批量做 K 个区间加法，最后一次性查询每个位置 → O(N + K) 而不是 O(NK)。

经典题：航班预订统计 LC 1109。

## 二维前缀和

```cpp
vector<vector<int>> pre(n + 1, vector<int>(m + 1, 0));
for (int i = 0; i < n; ++i)
    for (int j = 0; j < m; ++j)
        pre[i+1][j+1] = pre[i][j+1] + pre[i+1][j] - pre[i][j] + a[i][j];

// 子矩阵 (r1, c1) 到 (r2, c2) 之和：
auto sum = [&](int r1, int c1, int r2, int c2) {
    return pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1];
};
```

**容斥原理**——加上大矩形减去两个长条再补上重复减的小矩形。

经典题：二维区域和检索 LC 304、矩形求和 LC 308（动态版用[[fenwick-tree|二维树状数组]]）。

## 二维差分

```cpp
// 给子矩阵 [(r1,c1), (r2,c2)] 全部加 v
d[r1][c1]     += v;
d[r1][c2+1]   -= v;
d[r2+1][c1]   -= v;
d[r2+1][c2+1] += v;
```

最后做一次二维前缀和还原。

| "异或前缀" | `xorPre[i] = a[0] ^ ... ^ a[i-1]`，子段异或 = `xorPre[r+1] ^ xorPre[l]` |

## 与树形 / 图的扩展

### 树上前缀和

每个节点的"从根到它的路径和" = 前缀和。子树和 = 该节点子树根的前缀和（等价于差分）。

[[../../题目/0437-路径总和-III|你的 LC 437 笔记]] 用了这个技巧。

### 路径上的前缀和（LCA）

`path(u, v) 之和 = pre[u] + pre[v] - 2 * pre[lca(u, v)]`（如果是边权）或类似公式（如果是点权）。

## 易错点

- 偏移搞错：`pre[i]` 表示"前 i 个"还是"a[0..i]"？**全程一致**
- 区间 `[l, r]` 还是 `[l, r)`？**全程一致**
- 求差分时 `d[r+1]` 越界需要 `vector<int> d(n+1)` 而不是 `n`
- 二维前缀和容斥忘加最小那块 → 答案错
- 异或前缀和不是"前缀异或" 的奇怪写法 → 用同样的差减思路
