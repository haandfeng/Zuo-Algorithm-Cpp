# 278. 第一个错误的版本

[LeetCode 链接](https://leetcode.cn/problems/first-bad-version/)

## 来源：题单 / Grind75

二分法，建议先看下面的基础二分
```python

class Solution:
    def firstBadVersion(self, n: int) -> int:
        left, right = 1, n # 左闭右闭指的是，要看的数的范围，从0到len-1
        while left <= right:
            # nums < left is good, nums > right is bad
            mid = (left+right) // 2
            if isBadVersion(mid):
                right = mid - 1
            else:
                left = mid + 1
        return right+1
```
