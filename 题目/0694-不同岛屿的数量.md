# 694. 不同岛屿的数量

[LeetCode 链接](https://leetcode.cn/problems/number-of-distinct-islands/)

## 来源：labuladong / DFS 图回溯 岛屿 相关 问题

比如题目输入下面这个二维矩阵：


![](https://labuladong.online/images/algo/island/5.jpg)
其中有四个岛屿，但是左下角和右上角的岛屿形状相同，所以不同的岛屿共有三个，算法返回 3。

很显然我们得想办法把二维矩阵中的「岛屿」进行转化，变成比如字符串这样的类型，然后利用 HashSet 这样的数据结构去重，最终得到不同的岛屿的个数。

如果想把岛屿转化成字符串，说白了就是序列化，序列化说白了就是遍历嘛。

==首先，对于形状相同的岛屿，如果从同一起点出发，dfs 函数遍历的顺序肯定是一样的。因为遍历顺序是写死在你的递归函数里面的，不会动态改变：==

用遍历顺序要序列化

假设它们的遍历顺序是：


下，右，上，撤销上，撤销右，撤销下
如果我用分别用 1, 2, 3, 4 代表上下左右，用 -1, -2, -3, -4 代表上下左右的撤销，那么可以这样表示它们的遍历顺序：


2, 4, 1, -1, -4, -2
你看，这就相当于是岛屿序列化的结果，只要每次使用 dfs 遍历岛屿的时候生成这串数字进行比较，就可以计算到底有多少个不同的岛屿了。

一定要记录「撤销」操作吗？

>细心的读者问到，为什么记录「撤销」操作才能唯一表示遍历顺序呢？不记录撤销操作好像也可以？不对，实际上必须记录撤销操作。
>比方说「下，右，撤销右，撤销下」和「下，撤销下，右，撤销右」显然是两个不同的遍历顺序，但如果不记录撤销操作，那么它俩都是「下，右」，成了相同的遍历顺序，显然是不对的。

```python
from typing import List

class Solution:
    def numDistinctIslands(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        islands = set()

        def dfs(i: int, j: int, path: List[str], direction: int) -> None:
            # 边界条件：越界或遇到水
            if i < 0 or i >= m or j < 0 or j >= n or grid[i][j] == 0:
                return

            # 标记为已访问
            grid[i][j] = 0

            # 记录进入该节点的方向
            path.append(str(direction))
            path.append(',')

            # 固定顺序 DFS（上、下、左、右）
            dfs(i - 1, j, path, 1)  # up
            dfs(i + 1, j, path, 2)  # down
            dfs(i, j - 1, path, 3)  # left
            dfs(i, j + 1, path, 4)  # right

            # 记录离开该节点（后序）
            path.append(str(-direction))
            path.append(',')

        # 扫描整个网格
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 1:
                    path = []
                    # 起始方向随意，但必须固定
                    dfs(i, j, path, 666)
                    islands.add(''.join(path))

        return len(islands)
```
