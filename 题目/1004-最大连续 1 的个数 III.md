# 1004. 最大连续 1 的个数 III

[LeetCode 链接](https://leetcode.cn/problems/max-consecutive-ones-iii/)

## 来源：灵茶山艾府和代码随想录 / 滑动窗口(同向双指针)

[[最大连续1的个数]]

==学会转化问题==

这次的转化是： 计算为0的次数，和重复字符一个道理
```c++
int longestOnes(vector<int>& nums, int k) {  
    int ans = 0,left=0;  
    int count = 0;  
    for (int right = 0; right < nums.size(); right++) {  
        if (nums[right] == 0) {  
            ++count;  
        }  
        while (count > k) {  
            if (nums[left++] == 0) {  
                --count;  
            }  
        }  
        ans = max(ans, right - left + 1);  
    }  
    return ans;  
}
```

他的转换更精辟

统计窗口内 0 的个数 cnt0​，则问题转换成在 cnt0​≤k 的前提下，窗口大小的最大值。

```c++
class Solution {
public:
    int longestOnes(vector<int>& nums, int k) {
        int ans = 0, left = 0, cnt0 = 0;
        for (int right = 0; right < nums.size(); right++) {
            cnt0 += 1 - nums[right]; // 0 变成 1，用来统计 cnt0
            while (cnt0 > k) {
                cnt0 -= 1 - nums[left++];
            }
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```
