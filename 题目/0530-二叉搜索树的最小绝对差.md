# 530. 二叉搜索树的最小绝对差

[LeetCode 链接](https://leetcode.cn/problems/minimum-absolute-difference-in-bst/)

## 来源：灵茶山艾府和代码随想录 / 二叉树

中序遍历，升序，看pre和当前结果
根据条件 node 一定大于 0
```c++
int pre = -1;  
int min1 = INT_MAX;  
int getMinimumDifference(TreeNode* root) {  
    if (root == nullptr) return 0;  
    getMinimumDifference(root->left);  
    if (pre!=-1) {  
        min1 = min(abs(root->val - pre), min1);  
    }  
    pre = root->val;  
    getMinimumDifference(root->right);  
    return min1;  
}
```

## 双指针法
一个指针指向前面，一个指针指向cur
`if pre!= nullptr` 判断是不是第一个
