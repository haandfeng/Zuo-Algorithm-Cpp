# 1047. 删除字符串中的所有相邻重复项

[LeetCode 链接](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/)

## 来源：灵茶山艾府和代码随想录 / 栈和队列

和有效括号差不多，删除相邻的元素用栈就很合适

用栈保存刚刚遍历过的元素

可以用字符串模拟栈的行为，这样就不需要再把结果反过来了

```c++
string removeDuplicates(string s) {  
    stack<char> st;  
    for (int i = 0; i < s.size(); ++i) {  
        if (st.empty()) {  
            st.push(s[i]);  
        }else {  
            if (st.top() == s[i]) {  
                st.pop();  
            }else {  
                st.push(s[i]);  
            }  
        }  
    }  
    s.resize(st.size());  
    for (int i =  s.size() -1; i >=0; --i) {  
        s[i] = st.top();  
        st.pop();  
    }  
    return s;  
}
```
