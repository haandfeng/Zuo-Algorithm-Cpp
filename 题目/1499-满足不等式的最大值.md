# 1499. 满足不等式的最大值

[LeetCode 链接](https://leetcode.cn/problems/max-value-of-equation/)

## 来源：灵茶山艾府和代码随想录 / 单调队列

![[Pasted image 20251015203953.png]]

难度不高，但单调队列的模版和滑动窗口的模版弄混了。导致没想出来
```python
class Solution:
    def findMaxValueOfEquation(self, points: List[List[int]], k: int) -> int:
        ans = -inf
        q = deque()
        for x, y in points:
            while q and q[0][0] < x - k:  # 队首超出范围
                q.popleft()  # 弹它！
            if q:
                ans = max(ans, x + y + q[0][1])  # 加上最大的 yi-xi
            while q and q[-1][1] <= y - x:  # 队尾不如新来的强
                q.pop()  # 弹它！
            q.append((x, y - x))
        return ans
```
