# 338. 比特位计数

[LeetCode 链接](https://leetcode.cn/problems/counting-bits/)

## 来源：题单 / Blind75

对于所有的数字，只有两类：

奇数：二进制表示中，奇数一定比前面那个偶数多一个 1，因为多的就是最低位的 1。
          举例： 
         0 = 0       1 = 1
         2 = 10      3 = 11
偶数：二进制表示中，偶数中 1 的个数一定和除以 2 之后的那个数一样多。因为最低位是 0，除以 2 就是右移一位，也就是把那个 0 抹掉而已，所以 1 的个数是不变的。
           举例：
          2 = 10       4 = 100       8 = 1000
          3 = 11       6 = 110       12 = 1100


```java
class Solution {
    public int[] countBits(int n) {
        int[] res = new int [n+1];
        for(int i = 1; i <=n; i++){
            if(i % 2 == 0){
                res[i] = res[i/2];
            }else{
                res[i] = res[i-1] + 1;
            }

        }
    return res;
    }
}
```
