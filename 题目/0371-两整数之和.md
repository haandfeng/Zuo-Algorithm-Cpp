# 371. 两整数之和

[LeetCode 链接](https://leetcode.cn/problems/sum-of-two-integers/)

## 来源：题单 / Blind75

和 s =（非进位和 n ）+（进位 c ）。
即可将 s=a+b 转化为：
s=a+b⇒s=n+c
```python
class Solution(object):
    def getSum(self, a, b):
        """
        :type a: int
        :type b: int
        :rtype: int
        """
        # 2^32
        MASK = 0x100000000
        # 整型最大值
        MAX_INT = 0x7FFFFFFF
        MIN_INT = MAX_INT + 1
        while b != 0:
            # 计算进位
            carry = (a & b) << 1 
            # 取余范围限制在 [0, 2^32-1] 范围内
            a = (a ^ b) % MASK
            b = carry % MASK
        return a if a <= MAX_INT else ~((a % MIN_INT) ^ MAX_INT)   
```
