# 2466. 统计构造好字符串的方案数

[LeetCode 链接](https://leetcode.cn/problems/count-ways-to-build-good-strings/)

## 来源：灵茶山艾府和代码随想录 / 动态规划

都是选or不选的问题
和爬楼梯思路差不多，第一不过是之前只能爬1和2，这里是 one 和zero阶梯

```java
class Solution {
    public int countGoodStrings(int low, int high, int zero, int one) {
        final int MOD = 1_000_000_007;
        int ans = 0;
        int[] f = new int[high + 1]; // f[i] 表示构造长为 i 的字符串的方案数
        f[0] = 1; // 构造空串的方案数为 1
        for (int i = 1; i <= high; i++) {
            if (i >= zero) f[i] = f[i - zero];
            if (i >= one)  f[i] = (f[i] + f[i - one]) % MOD;
            if (i >= low)  ans = (ans + f[i]) % MOD;
        }
        return ans;
    }
}
```


```python
class Solution:
    def countGoodStrings(self, low: int, high: int, zero: int, one: int) -> int:
        MOD = 1_000_000_007
        @cache  # 缓存装饰器，避免重复计算 dfs 的结果（记忆化）
        def dfs(i: int) -> int:
            if i < 0:
                return 0
            if i == 0:
                return 1
            # 提前取模，不然结果会是天文数字，没有那么多空间存得下来
            return (dfs(i - zero) + dfs(i - one)) % MOD
        return sum(dfs(i) for i in range(low, high + 1)) % MOD
```
