# 1020. 飞地的数量

[LeetCode 链接](https://leetcode.cn/problems/number-of-enclaves/)

## 来源：灵茶山艾府和代码随想录 / 图

[卡码网：101. 孤岛的总面积](https://kamacoder.com/problempage.php?pid=1173)
反向思考，不是孤岛更好解决：
1.从border出发的岛都不是孤岛
2.从飞其他地方出发的岛就是孤岛
把不是孤岛染色成2。染完后找1就好了

```python
from typing import List

class Solution:
    def numEnclaves(self, grid: List[List[int]]) -> int:
        n, m = len(grid), len(grid[0])

        def dfs(r: int, c: int) -> None:
            # 越界 or 非陆地，直接返回
            if r < 0 or r >= n or c < 0 or c >= m or grid[r][c] != 1:
                return
            # 标记为“非孤岛”
            grid[r][c] = 2
            # 四个方向继续扩展
            dfs(r + 1, c)
            dfs(r - 1, c)
            dfs(r, c + 1)
            dfs(r, c - 1)

        # 1) 从边界出发，把所有能连到边界的陆地染成 2
        for c in range(m):
            if grid[0][c] == 1:
                dfs(0, c)
            if grid[n - 1][c] == 1:
                dfs(n - 1, c)

        for r in range(n):
            if grid[r][0] == 1:
                dfs(r, 0)
            if grid[r][m - 1] == 1:
                dfs(r, m - 1)

        # 2) 剩下的 1 就是孤岛，统计面积
        ans = 0
        for r in range(n):
            for c in range(m):
                if grid[r][c] == 1:
                    ans += 1
        return ans
```
