# 58. 最后一个单词的长度

[LeetCode 链接](https://leetcode.cn/problems/length-of-last-word/)

## 来源：题单 / Grind75

从后往前遍历, 从不是空格开始便利

```python
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        start = False
        cnt = 0
        for i in range(len(s)-1, -1, -1):
            ch = s[i]
            if not start and ch != ' ':
                cnt = 1
                start = True
            elif start and ch != ' ':
                cnt += 1
            elif start and ch == ' ':
                return cnt
        return cnt
```
