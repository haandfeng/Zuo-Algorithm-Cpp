0x3f的，感觉思路描述的挺不错的
问：兔子会不会「跳过」乌龟，从来不会和乌龟相遇呢？

答：这是不可能的。如果有环的话，那么兔子和乌龟都会进入环中。这时用「相对速度」思考，==乌龟不动，兔子相对乌龟每次只走一步，这样就可以看出兔子一定会和乌龟相遇了。==

```c++
class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode *slow = head, *fast = head; // 乌龟和兔子同时从起点出发
        while (fast && fast->next) {
            slow = slow->next; // 乌龟走一步
            fast = fast->next->next; // 兔子走两步
            if (fast == slow) // 兔子追上乌龟（套圈），说明有环
                return true;
        }
        return false; // 访问到了链表末尾，无环
    }
};
```

```c++
class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        while (fast && fast->next) {
            slow = slow->next;
            fast = fast->next->next;
            if (fast == slow) { // 相遇
                while (slow != head) { // 再走 a 步
                    slow = slow->next;
                    head = head->next;
                }
                return slow;
            }
        }
        return nullptr;
    }
};
```

```python
class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        slow, fast = head, head
        while fast != None and fast.next != None:
            slow = slow.next
            fast = fast.next.next
```

## 来源：labuladong / 双指针-链表 和 链表代码实现

文远知行考过：一定要走多1步吗，走多两步行不行，怎么证明他的正确性？



标准做法：fast 走 2 步，slow 走 1 
**为什么一定能相遇？**
一旦两个指针都进入环，设环长为 C，某时刻 fast 比 slow 超前 d 步。
每轮迭代，fast 走 2、slow 走 1，**相对距离每步缩小 1**。
经过 d 步后，差距变为 0，必然相遇。✅

---

fast 走 3 步行不行？
**不一定行。**
fast 走 3、slow 走 1，每步相对距离增加 2（fast 追得更快）。
要相遇，需要满足：
```
d + 2k ≡ 0 (mod C)
```
有解的条件是 `gcd(2, C) | d`。
**反例**：C = 4（偶数环），初始差距 d = 1（奇数）
```
2k ≡ -1 (mod 4)  →  无整数解
```
fast 和 slow **永远不会相遇**，算法失效。❌

```go
func middleNode(head *ListNode) *ListNode {
    // 快慢指针初始化指向 head
    slow, fast := head, head
    // 快指针走到末尾时停止
    for fast != nil && fast.Next != nil {
        // 慢指针走一步，快指针走两步
        slow = slow.Next
        fast = fast.Next.Next
    }
    // 慢指针指向中点
    return slow
}
```
