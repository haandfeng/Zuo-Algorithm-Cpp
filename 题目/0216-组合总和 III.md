# 216. 组合总和 III

[LeetCode 链接](https://leetcode.cn/problems/combination-sum-iii/)

## 来源：灵茶山艾府和代码随想录 / 回溯

剪枝：
1. 元素的个数
2. 最大的结果都小于target
3. 最小的结果都大于target
我的答案懒得写了，差不多就剪枝哪里少了一个最大的结果都小于target，用等差数列计算
```c++
class Solution {
public:
    vector<vector<int>> combinationSum3(int k, int n) {
        vector<vector<int>> ans;
        vector<int> path;
        auto dfs = [&](this auto&& dfs, int i, int t) {
            int d = k - path.size(); // 还要选 d 个数
            if (t < 0 || t > (i * 2 - d + 1) * d / 2) // 剪枝
                return;
            if (d == 0) { // 找到一个合法组合
                ans.emplace_back(path);
                return;
            }

            // 不选 i
            if (i > d) {
                dfs(i - 1, t);
            }

            // 选 i
            path.push_back(i);
            dfs(i - 1, t - i);
            path.pop_back();
        };
        dfs(9, n);
        return ans;
    }
};
```
