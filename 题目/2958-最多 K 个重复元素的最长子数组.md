# 2958. 最多 K 个重复元素的最长子数组

[LeetCode 链接](https://leetcode.cn/problems/length-of-longest-subarray-with-at-most-k-frequency/)

## 来源：灵茶山艾府和代码随想录 / 滑动窗口(同向双指针)

[[至少有K个重复字符的最长子串]]
思路和上题差不多，把set改成了map
```c++
int maxSubarrayLength(vector<int>& nums, int k) {  
    int n = nums.size();  
    map<int, int> hashtable;  
    int left=0;  
    int result = 0;  
    for (int right = 0; right < n; ++right) {  
        int c = nums[right];  
        if (hashtable.find(c)!=hashtable.end()) {  
            hashtable[c]++;  
            while (hashtable[c] > k) {  
                --hashtable[nums[left++]];  
            }  
        }else {  
            hashtable[c] = 1;  
        }  
        result = max(result, right - left + 1);  
    }  
}
```


0x3f
优化了对map的使用，速度更快
```c++
class Solution {
public:
    int maxSubarrayLength(vector<int> &nums, int k) {
        int ans = 0, left = 0;
        unordered_map<int, int> cnt;
        for (int right = 0; right < nums.size(); right++) {
            cnt[nums[right]]++;
            while (cnt[nums[right]] > k) {
                cnt[nums[left++]]--;
            }
            ans = max(ans, right - left + 1);
        }
        return ans;
    }
};
```
