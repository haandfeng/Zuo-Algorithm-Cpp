# 2730. 找到最长的半重复子字符串

[LeetCode 链接](https://leetcode.cn/problems/find-the-longest-semi-repetitive-substring/)

## 来源：灵茶山艾府和代码随想录 / 滑动窗口(同向双指针)

没什么区别，注意边界条件的判定，最后+2，因为往滑动窗口右边看了
```c++
int longestSemiRepetitiveSubstring(string s) {  
    int n = s.length(), ans = 0;  
    if (n==0) return 0;  
    if (n==1) return s.length();  
  
    int left = 0, right = 0;  
    int pair = 0;  
    while (right < n-1) {  
        char c = s[right];  
        if (s[right] == s[right+1]) {  
            ++pair;  
        }  
        while (pair > 1) {  
            if (s[left] == s[left+1]) {  
                --pair;  
            }  
            ++left;  
        }  
        if (pair <= 1) {  
            ans = max(ans, right - left + 2);  
        }  
        ++right;  
    }  
    return ans;  
}
```
