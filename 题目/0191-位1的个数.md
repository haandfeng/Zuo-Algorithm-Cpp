# 191. 位1的个数

[LeetCode 链接](https://leetcode.cn/problems/number-of-1-bits/)

## 来源：题单 / Blind75

```java
    public int hammingWeight(int n) {
        int cnt = 0;
        for(int i = 0; i < 32; ++i){
            if ((n & 1) == 1){
                ++cnt;
            }
            n >>>= 1;
        }
        return cnt;
    }
```
