# 344. 反转字符串

[LeetCode 链接](https://leetcode.cn/problems/reverse-string/)

## 来源：灵茶山艾府和代码随想录 / 字符串

头尾交换
[[反转字符串]]
```c++
void reverseString(vector<char>& s) {  
    int left = 0, right = s.size() - 1;  
    while (left < right) {  
        swap(s[left], s[right]);  
        ++left;  
        --right;  
    }  
}
```
