# 90. 子集 II

## 来源：灵茶山艾府和代码随想录 / 回溯

[[子集]]
[[打印一个字符串无重复的全部子序列]]
[[常见递归题目]]
和组合组和的套路差不多，重复的话就用这个语句，只有遇到第一次一样的才用，其他时候都跳过
```c++
void bT7(vector<vector<int>>& ans, vector<int>& nums, vector<int>& path, int i) {  
    ans.emplace_back(path);  
    if (i==nums.size()) {  
        return;  
    }  
    for (int j=i; j<nums.size(); j++) {  
        if (j>i && nums[j]==nums[j-1]) {continue;}  
        path.push_back(nums[j]);  
        bT7(ans,nums,path,j+1);  
        path.pop_back();  
    }  
}  
vector<vector<int>> subsetsWithDup(vector<int>& nums) {  
    vector<vector<int>> ans;  
    vector<int> path;  
    sort(nums.begin(),nums.end());  
    bT7(ans,nums,path,0);  
    return ans;  
}
```

## 来源：labuladong / DFS 图回溯 岛屿 相关 问题

体现在代码上，需要先进行排序，让相同的元素靠在一起，如果发现 nums[i] == nums[i-1]，则跳过：
```python
class Solution:
    def __init__(self):
        self.res = []
        self.track = []
    
    def subsetsWithDup(self, nums: List[int]) -> List[List[int]]:
        # 先排序，让相同的元素靠在一起
        nums.sort()
        self.backtrack(nums, 0)
        return self.res
    
    def backtrack(self, nums: List[int], start: int) -> None:
        # 前序位置，每个节点的值都是一个子集
        self.res.append(self.track[:])
        
        for i in range(start, len(nums)):
            # 剪枝逻辑，值相同的相邻树枝，只遍历第一条
            if i > start and nums[i] == nums[i - 1]:
                continue
            self.track.append(nums[i])
            self.backtrack(nums, i + 1)
            self.track.pop()
```
