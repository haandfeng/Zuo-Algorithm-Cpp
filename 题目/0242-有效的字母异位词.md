# 242. 有效的字母异位词

## 来源：灵茶山艾府和代码随想录 / 哈希表

[[有效的字母异位词]]

哈希表统计数量

可以用数组计算，ascll 码

++ 然后-- 最后再判断是不是全为0，节省空间
记得初始化数组
```c++
bool isAnagram(string s, string t) {  
    int arr[26] ={};  
    for (int i = 0; i < s.length(); ++i) {  
        ++arr[s[i] - 'a'];  
    }  
    for (int i = 0; i < t.length(); ++i) {  
        --arr[t[i] - 'a'];  
    }  
    for (int i = 0; i < 26; ++i) {  
        if (arr[i]!=0) return false;  
    }  
    return true;  
}
```
