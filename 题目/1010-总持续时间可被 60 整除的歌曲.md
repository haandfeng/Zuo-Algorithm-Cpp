# 1010. 总持续时间可被 60 整除的歌曲

[LeetCode 链接](https://leetcode.cn/problems/pairs-of-songs-with-total-durations-divisible-by-60/)

## 来源：题单 / Grind75

```python
from typing import List

class Solution:
    def numPairsDivisibleBy60(self, time: List[int]) -> int:
        d = {}
        ans = 0
        for t in time:
            r = t % 60
            # 边界处理：如果余数为0，对应的补数也是0
            complement = (60 - r) % 60
            
            if complement in d:
                ans += d[complement]
            
            d[r] = d.get(r, 0) + 1
            
        return ans
```
