# 237. 删除链表中的节点

[LeetCode 链接](https://leetcode.cn/problems/delete-node-in-a-linked-list/)

## 来源：灵茶山艾府和代码随想录 / 链表

[[删除链表中的节点]]
[[不给头结点,删除单链表上的节点]]
把下一个节点copy下来，删除下一个节点
```c++
void deleteNode(ListNode* node) {  
      
    node->val = node->next->val;  
    ListNode *prev = node->next;  
    node->next = node->next->next;  
    delete prev;  
}
```

0x3f
==被删除节点的内存没有被真正释放，仅仅从逻辑上跳过。==
```c++
class Solution {
public:
    void deleteNode(ListNode* node) {
        *node = *node->next;
    }
};
```
