# 2008. 出租车的最大盈利

[LeetCode 链接](https://leetcode.cn/problems/maximum-earnings-from-taxi/)

## 来源：题单 / Grind75

一样的题目了
```python
class Solution:
    def maxTaxiEarnings(self, n: int, rides: List[List[int]]) -> int:
        rides.sort(key= lambda  x:(x[1],x[2]))
        dp = [0] * (len(rides)+1)
        ends = [e for _,e,_ in rides]
        for i in range(1, len(rides)+1):
            st, et, val = rides[i-1][0], rides[i-1][1], rides[i-1][2]
            idx = bisect_right(ends,st,hi=i-1)
            dp[i] = max(
                dp[i-1],
                dp[idx]+et-st+val
            )
        return dp[-1]
```
