# 67. 二进制求和

[LeetCode 链接](https://leetcode.cn/problems/add-binary/)

## 来源：题单 / Grind75

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        ans = []
        carry = 0
        i, j = len(a) - 1, len(b) - 1

        while i >= 0 or j >= 0:
            total = carry
            if i >= 0:
                total += int(a[i])
                i -= 1
            if j >= 0:
                total += int(b[j])
                j -= 1

            ans.append(str(total % 2))
            carry = total // 2

        if carry == 1:
            ans.append("1")

        return "".join(reversed(ans))
```
