# 17. 电话号码的字母组合

[LeetCode 链接](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

## 来源：灵茶山艾府和代码随想录 / 回溯

[[电话号码的字母组合]]
0x3f分类成子集，我觉得不是，是组合问题
三问：
1. 枚举path[i]要填入的字母
2. 构造字符串>=i的部分
3. 构造字符串>=i+1的部分
dfs(i) -> dfs(i+1)

首先构造一个数组mapping数组和字母

```c++
class Solution {  
    string MAPPING[10] = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};  
public:  
    void lC(string& path, string& digits, vector<string>& ans,int i) {  
          if(i == path.size()) {  
            ans.push_back(path);  
            return;  
          }  
          for(char c : MAPPING[digits[i] - '0']){  
               path[i] = c;  
               lC(path, digits, ans,i+1);  
          }  
    }  
    vector<string> letterCombinations(string digits) {  
        int n = digits.length();  
        if (n == 0) {  
            return {};  
        }  
        vector<string> ans;  
        string path(n, 0); // 注意 path 长度一开始就是 n，不是空串  
        lC(path, digits, ans,0);  
        return ans;  
    }  
};
```
