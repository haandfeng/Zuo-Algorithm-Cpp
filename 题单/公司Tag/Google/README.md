# Google 面试题

> 占位 README，开始刷 Google 题时往这里填。

## 面试特点

- **轮数**：phone screen + 4-5 onsite（多数算法）
- **风格**：注重**算法深度** + **数据结构选型**；偶尔 follow-up 进阶问题
- **代码语言**：自由选；现场 Google Doc 编辑（无 IDE）
- **常考主题**：
  - Trees / Graphs（最复杂的形态）
  - DP（中等到难）
  - 字符串、滑动窗口
  - 设计题
  - **数学 / 概率**（偶尔出现）
