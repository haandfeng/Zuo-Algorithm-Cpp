# Apple 面试题

> 占位 README，开始刷 Apple 题时往这里填。

## 面试特点

- **轮数**：phone screen + 4-6 onsite（高度依赖 team match）
- **风格**：**team-specific** —— 不同部门差别极大
  - 系统部门：底层 C / C++ / 内存 / 性能
  - iOS 部门：Swift / Objective-C
  - 算法部门：经典算法 + 数据结构
- **代码语言**：通常允许自选，但部分 team 要求特定语言
- **常考主题**：
  - 经典 LeetCode 中等题
  - 多线程 / 并发（系统岗）
  - **设计题 + 项目深挖**
