# Amazon 面试题

> 占位 README，开始刷 Amazon 题时往这里填。

## 面试特点

- **轮数**：OA + phone screen + 4-5 onsite（2-3 算法 + 1-2 行为/LP + 1 系统设计）
- **风格**：算法**简单到中等**居多；**14 条 Leadership Principles 非常重**
- **代码语言**：自由选
- **常考主题**：
  - 经典数据结构（Hash / Tree / Linked List）
  - BFS/DFS / 拓扑排序
  - 区间合并 / 调度
  - **OOD（设计停车场 / 电梯 / 社交网络）**
  - 系统设计（Senior 以上必考）

## 14 LP（Leadership Principles）

行为面会大量考。提前准备 STAR 故事覆盖：
- Customer Obsession / Ownership / Invent and Simplify / Are Right, A Lot
- Learn and Be Curious / Hire and Develop / Insist on Highest Standards
- Think Big / Bias for Action / Frugality / Earn Trust
- Dive Deep / Have Backbone / Deliver Results
